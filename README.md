# Temporizador hecho con tkinter

- En este programa vas a poder agregar temporizadores con su nombre (name de la actividad)
y la duración
- Para iniciar un temporizador, tenés que darle a "Iniciar"

Al crear un temporizador, se crea cuanto tiempo pasaste en esa actividad en el apartado "Historial".
Ahí podrás ver cuánto tiempo haz pasado en una actividad.

# <IMPORTANTE>
- En este programa NO se pueden pausar temporizadores o eliminarlos mientras están corriendo.
La idea del programa es que los temporizadores se completen. Si necesitas sacar un temporizador
en ejecución, cierra la ventana del programa.

# Mas funciones..
- Podés editar el nombre de un temporizador (mientras no esté en ejecución)
- Podés editar el nombre de un temporizador (mientras no esté en ejecución)
- Podés eliminar un temporizador (mientras no esté en ejecución)

# Requisitos
- No hace falta muchos requisitos. Tkinter viene con python. Y el programa no es pesado.
- Si no te corre, entonces tirate de un puente.
